> **Design reference.** The approved hybrid has been implemented. These raster
> assets are not the current product contract; see the

This alternate visual direction was generated in Google Stitch Redesign using
Nano Banana Pro after reviewing the current Adduce application in the browser.
All four delivered raster screens came from Redesign / Nano Banana Pro; the
Gemini Flash intermediates were excluded. The direction keeps the real Repo,
Service Map, Trace, 3D/2D, repository-scope, and Ingest structure while testing
a slightly denser, more operational graph treatment.

## Design intent

- Show the actual multi-repository graph grammar: circular nodes, thin edges,
  hub-and-spoke communities, repo labels, and a persistent inspector.
- Give the two repositories distinct but restrained forest and rust/ochre
  identities without turning node type into a rainbow.
- Keep the canvas graphite and the shell mineral so dense graph structure has
  contrast without glow.
- Make selected paths and nodes crisp while background relationships recede.
- Preserve the operational controls visible in the current product instead of
  replacing Adduce with a generic analytics dashboard.

These raster mocks are visual references. Visible copy and counts in the
implemented product must come from the current frontend contracts and runtime
state, not from pixels in the generated images.

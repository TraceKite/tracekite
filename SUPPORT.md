# Support

TraceKite is in public preview.

- Use [GitHub Issues](https://github.com/TraceKite/tracekite/issues) for
  reproducible bugs and feature requests.
- Use the repository documentation and existing issues before opening a new
  report.
- Use [`SECURITY.md`](SECURITY.md) for vulnerabilities. Never post secrets or
  private source in an issue.

Community support is best effort. There is currently no production support SLA.
